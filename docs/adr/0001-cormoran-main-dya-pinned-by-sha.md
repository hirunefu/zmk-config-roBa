# cormoran の main+dya 系統を SHA 固定で使う

DYA Studio（トラックボール調整、エンコーダ割り当て、慣性、マクロ/コンボの実行時編集など）を使い続けるため、ZMK は上流の正式版ではなく、cormoran 氏のフォークの main+dya 系統（Zephyr 4.1）を使う。v0.3+dya 系統は 2026-05-04 で更新が止まっており、DYA Studio の新機能は main+dya 系統にしかない。フォークにも上流の v0.4.0 にもリリースタグがないため、ZMK 本体・各モジュール・ビルドワークフローはすべてコミット SHA で固定し、上げるときは CI でビルドを確かめてから上げる。

## Considered Options

- 上流 ZMK だけを使う：DYA Studio の機能をすべて失うので見送った。
- v0.3+dya 系統のまま上げる：変更は小さいが、系統自体が更新停止で新機能も入らない。
- 上流 v0.4.0 のリリースを待つ：リリース時期が未定で、cormoran 側がタグに追従するかも分からない。

## Consequences

- DYA Studio の実行時設定は保存形式が変わるので、移行時に初期化して取り直す。
- 開発中のブランチ（エンコーダの custom-settings 版、OS 別既定レイヤー）にも依存するため、SHA を上げるときは各モジュールの互換を個別に確かめる。
